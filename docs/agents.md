\# BunnyEra AI Agents



BunnyEra AI agents represent departments inside the AI company.



\## Agents



\- AI CEO

\- Product Selection Agent

\- Listing Agent

\- Marketing Agent

\- Customer Service Agent

\- Finance Agent

\- Risk Review Agent



\## Design Principles



\- Each agent has a clear responsibility.

\- Each agent can be connected to workflows.

\- Each agent can use one or more prompt templates.

\- Agents should produce structured outputs.
